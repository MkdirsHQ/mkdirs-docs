---

<Steps>
  <Step>
    ### Install dependencies

    ```bash
    pnpm install
    ```
  </Step>
  <Step>
    ### Start the local site

    ```bash
    pnpm dev
    ```
  </Step>
  <Step>
    ### Update site identity

    Update `src/site.config.ts`, `wrangler.jsonc`, and assets in `public/`.
  </Step>
  <Step>
    ### Validate and deploy

    ```bash
    pnpm check
    pnpm deploy
    ```
  </Step>
</Steps>

## Content conventions

Add pages under `content/` and use `meta.json` to control navigation:

<Files>
  <Folder name="content" defaultOpen>
    <File name="index.mdx" />
    <File name="getting-started.mdx" />
    <File name="meta.json" />
  </Folder>
</Files>
