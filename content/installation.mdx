Learn how to launch your directory website with Mkdirs.

## Installation Guide

<Steps>
  <Step>
    ### Create your own repository

Click on `Fork` button on the top right corner of [mkdirs-template](https://github.com/MkdirsHQ/mkdirs-template) to create your own repository, set the name of the repository and make sure to set it to private.
  </Step>
  <Step>
    ### Clone the Github repository

```bash
git clone https://github.com/your-username/<your-repository-name>.git
```
  </Step>
  <Step>
    ### Install the dependencies

Make sure to install the dependencies (PNPM recommended).

```bash
cd <your-repository-name>
pnpm install
```
  </Step>
  <Step>
    ### Copy the `.env.example` file to `.env`

```bash
cp .env.example .env
```
  </Step>
  <Step>
    ### Configure the environment variables

Update the environment variables with your own values, learn more about configuring the environment variables [here](/configuration/sanity/).

```bash
# .env

# "http://localhost:3000" or "https://mkdirs.com"
NEXT_PUBLIC_APP_URL=

# -----------------------------------------------------------------------------
# Dataset & Storage (Sanity)
# -----------------------------------------------------------------------------
NEXT_PUBLIC_SANITY_DATASET=
NEXT_PUBLIC_SANITY_PROJECT_ID=
SANITY_API_TOKEN=

# -----------------------------------------------------------------------------
# Email (Resend)
# -----------------------------------------------------------------------------
RESEND_API_KEY=
RESEND_EMAIL_FROM=
RESEND_EMAIL_ADMIN=
RESEND_AUDIENCE_ID=

# -----------------------------------------------------------------------------
# Analytics (OpenPanel & Google Analytics)
# -----------------------------------------------------------------------------
NEXT_PUBLIC_OPENPANEL_CLIENT_ID=
NEXT_PUBLIC_GOOGLE_ANALYTICS_ID=

# -----------------------------------------------------------------------------
# Payment (Stripe)
# -----------------------------------------------------------------------------
STRIPE_API_KEY=
STRIPE_WEBHOOK_SECRET=
NEXT_PUBLIC_STRIPE_PRO_PRICE_ID=

# -----------------------------------------------------------------------------
# Authentication (NextAuth)
# -----------------------------------------------------------------------------
AUTH_SECRET=

AUTH_GOOGLE_ID=
AUTH_GOOGLE_SECRET=

AUTH_GITHUB_ID=
AUTH_GITHUB_SECRET=
```
  </Step>
  <Step>
    ### Start the development server

Start the development server and open it in your browser at http://localhost:3000

```bash
pnpm dev
```
  </Step>
  <Step>
    ### Build for production

Build the application to generate code for production.

```bash
pnpm build
```
  </Step>
  <Step>
    ### Deploy

Follow the deployment guides to deploy your application on your favorite platform.

<ul>
  <li><a href="/deployment/vercel">Vercel</a></li>
  <li><a href="/deployment/docker">Docker</a></li>
  <li><a href="/deployment/dokploy">Dokploy</a></li>
</ul>
  </Step>
</Steps>

## What's next?

Once you have deployed your application, it's recommended to set up a process to sync the source code from `MkdirsHQ/mkdirs-template` to your own repository if some updates are available, for example, new features or bug fixes.

Learn more about how to sync the source code in the [Development](/guide/develop) section.
