icon: Rocket
---

<Steps>
  <Step>
    ### 安装依赖

    ```bash
    pnpm install
    ```
  </Step>
  <Step>
    ### 启动本地网站

    ```bash
    pnpm dev
    ```
  </Step>
  <Step>
    ### 修改站点信息

    更新 `src/site.config.ts`、`wrangler.jsonc` 和 `public/` 中的资源。
  </Step>
  <Step>
    ### 验证并部署

    ```bash
    pnpm check
    pnpm deploy
    ```
  </Step>
</Steps>

## 内容约定

在 `content/` 中添加页面，并通过 `meta.json` 控制导航：

<Files>
  <Folder name="content" defaultOpen>
    <File name="index.mdx" />
    <File name="getting-started.mdx" />
    <File name="meta.json" />
  </Folder>
</Files>
