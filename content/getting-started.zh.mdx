<Steps>
  <Step>
    ### 安装依赖

    ```bash
    pnpm install
    ```
  </Step>
  <Step>
    ### 启动本地网站

    ```bash
    pnpm dev
    ```
  </Step>
  <Step>
    ### 修改站点信息

    编辑 `src/site.config.ts`、`wrangler.jsonc` 和 `public/` 中的资源。
  </Step>
  <Step>
    ### 验证并部署

    ```bash
    pnpm check
    pnpm deploy
    ```
  </Step>
</Steps>

## 内容约定

英文是默认语言。简体中文翻译在扩展名前添加 `.zh`：

  </Folder>
