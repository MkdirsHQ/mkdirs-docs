## Guided steps

<Steps>
  <Step>
    ### Create the page

    Add an `.mdx` file under `content/`.
  </Step>
  <Step>
    ### Add its translation

    Create a matching `.zh.mdx` file when the page is bilingual.
  </Step>
  <Step>
    ### Add navigation metadata

    Put the page slug in the nearest `meta.json` and `meta.zh.json` files.
  </Step>
</Steps>

## Accordions

<Accordions>
  <Accordion title="Where should reusable behavior live?">
    Put it in the template, then keep derived sites focused on content.
  </Accordion>
  <Accordion title="Can a page use React components?">
    Yes. Register a component in `getMdxComponents()` and it becomes available to every MDX page.
  </Accordion>
  <Accordion title="Do translated pages need imports?">
    No. English and Chinese pages receive the same global component set.
  </Accordion>
</Accordions>

## Video

Use the global `YoutubeVideo` component without importing it inside MDX. It is responsive and includes sensible iframe permissions by default:

```mdx
<YoutubeVideo url="https://www.youtube.com/embed/VIDEO_ID" />
```

<YoutubeVideo
  url="https://www.youtube.com/embed/5tfid3SIq00"
  title="Documentation video example"
/>
