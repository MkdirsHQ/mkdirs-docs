模板会构建静态 FumaPress 网站，并通过 Cloudflare Workers Static Assets 发布。

<Steps>
  <Step>
    ### 设置站点信息

    更新 `src/site.config.ts`、`public/robots.txt`，以及 `wrangler.jsonc` 中的 Worker 名称。
  </Step>
  <Step>
    ### 登录 Wrangler

    本地使用 `wrangler login`，或在 CI 中提供 `CLOUDFLARE_API_TOKEN` 和 `CLOUDFLARE_ACCOUNT_ID`。
  </Step>
  <Step>
    ### 执行完整验证

    ```bash
    pnpm check
    ```

    这个命令会检查内容源、TypeScript、生产构建和 Wrangler dry run。
  </Step>
  <Step>
    ### 部署

    ```bash
    pnpm deploy
    ```
  </Step>
</Steps>

## 自定义域名

域名由 Cloudflare 管理时，可以添加 Worker Custom Domain：

```json
{
  "routes": [
    {
      "pattern": "docs.example.com",
      "custom_domain": true
    }
  ]
}
```

<Callout type="warn" title="检查现有 DNS">
  部署路由前检查是否存在冲突的 CNAME。
</Callout>
